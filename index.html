Video Upload API

This website provides information about a tool used to upload video files to Google Drive.

The tool is intended for use by its owner. When authorized, it can connect to Google Drive to upload video files and provide links to files stored there.

Google account access

Access is granted by the user through Google's OAuth authorization process. Access can be revoked at any time from the user's Google Account security settings.
